# 更新记录

作者 **Asryto**。扩展市场按版本显示这里的说明。

## 0.4.11

- 修复气泡同步在 Coopanion 0.2.1 上被判为「缺少显示适配桥」：判定从写死的桌宠版本号（只认 0.1.4）改成按能力检查——页面里有没有钩子标记、浏览器端脚本在不在、四个调用点是否齐全。桌宠 0.2.0 已经内置这套钩子，之前却被版本号挡在门外。
- 安装脚本在钩子已存在时直接成功并同步浏览器端脚本，不再因版本不同而拒绝；只有确实需要打补丁、且版本未经核对的桌宠才报错。
- 未改动模型、音色、采样参数与内存保护线。

## 0.4.10

- 升级到 world 契约 **6**：实例接口 `console()` 改为 `webUi()`，清单字段改为 `webUiClient` / `webUiStyle`，面板产物更名为 `webui-0.4.10.js` / `webui-0.4.10.css`。0.4.9 及更早的包仍能被框架过渡层加载，但下一个大版本起不再加载。
- 新增自描述 `describe.json`（工具、事件与 envPrompt 模板原文），由 `npm run describe` 生成，CI 核对它与代码一致。
- 没有核显的电脑不再卡在设备选择：一键部署会列出检测到的显卡并要求确认，按钮显示「使用所选设备继续部署」，同时说明模型已下载、不会重复下载。独显仍只能由用户显式指定。
- 部署的测试阶段说明首次运行需要编译显卡着色器，独显上可能多等 20–30 秒，之后不再需要。
- 未改动模型、音色、采样参数与内存保护线。

## 0.4.9

- 部署入口在未安装时显示「一键部署」，已有模型显示「已部署」并说明无需重复下载；手动部署指南只在失败后显示。
- 需要重启桌宠才能生效。
