# 本地语音助手 World

独立的 Coopanion API 5 World 扩展。无需安装 CosyVoice 或其他语音扩展。
依赖本仓库提供的 Qwen3-TTS 核显 Python 运行环境，保留固定 soft-child-design-2 音色。

先按仓库核显部署指南运行 `scripts/setup-native.ps1`，然后退出 Coopanion：

```powershell
.runtime-native\venv\Scripts\python.exe scripts/install_world.py --extensions "你的扩展目录" --bot "你的 Bot 目录" --runtime .runtime-native --enable
```

安装器创建当前机器的路径配置，备份旧配置，注销旧 CosyVoice 插件但不删除旧文件。
重启后打开 **本地语音助手 → 语音控制**。无需修改源码中的机器路径。

支持启停、试听、静音、音量、队列上限、过期丢弃、清队列、内存恢复重试与流式播放指标。
语速锁定 1.0；底层已确认的播放链路不支持变速，故不展示无效滑块。
静音跳过新语句；立即停止会中断当前句并释放模型。发生合成错误不自动重复半句。
内存不足会退回文字。界面根据实际运行时显示启动与恢复保护线：常规 4 / 4.5 GiB，已验证精简布局 3.25 / 3.75 GiB。

源码安装后可在 `world` 目录运行 `npm test`、`npm pack` 打包独立 npm 扩展。
模型、工具链和 Python 依赖通过仓库安装脚本获取，npm 包不内置大型模型。
旧插件的消息解析/日志监听代码按 MIT 派生；许可证保留。运行时无旧插件导入或调用。


### 低功耗模式（0.3.5）

语音控制页和配置页均提供总开关。新安装默认关闭；已有自动休眠配置迁移为开启，保留原有阈值。开启后，仅在没有播放、排队、加载或切换操作时，按空闲时间或低内存条件休眠。下一句话自动唤醒并增加首句等待；关闭后会恢复已休眠的模型（内存不足则等待），不再自动休眠。关闭此模式不会绕过加载保护，也不更改系统电源计划。

默认休眠条件为 300 秒、1536 MiB；各条件填 0 分别关闭。可选保留工作进程（仍有常驻开销）或完全退出进程。开关已收进播放卡片内的单行控制栏，详细解释折叠；配置页仍可设置全部条件。

启动保护线属于系统可用内存，不是模型固定占用。固定音色精简模型 + KV 1024 + compactGraphs 三项同时满足时，加载/唤醒要求 3.25 GiB，自动恢复要求 3.75 GiB；其他布局保持 4 / 4.5 GiB。2026-10-14 本机两轮在原生加载检查点均为约 3.36 GiB 可用内存，成功加载并生成长短句，音频 SHA256 与已确认音色逐字节一致；这不是游戏负载或所有核显的保证。原生引擎拒绝低于保护线的加载，界面和自动恢复按实际布局显示对应门槛。

界面另显示当前语音进程专用提交、驻留与历史驻留峰值，数据在加载、播放结束、休眠后采集，不逐帧轮询。进程计数未单列核显共享内存，不能与系统可用内存直接相减；后台未回传数据时显示尚无实测。低功耗只减少空闲占用，不减少合成时的需求。

主按钮统一控制启停：关闭时“开启语音”，加载时“加载中 · 点击取消”，就绪或休眠时“停止语音”。点击加载中的按钮会取消并释放工作进程。校验、模型加载、准备音色和播放器阶段及等待时间在状态区域显示；不编造百分比。重试恢复仅在故障/内存不足/环境待配置时出现。内存卡片只更新数据，不重建折叠说明，定时刷新保留展开状态。

### 0.3.6 / Python 0.4.9：文字词表按需加载

新版原生补丁只把当前文本需要的词表条目上传核显，原始权重字节和采样参数保持不变。满足原精简布局并启用 `streamTextEmbedding: true` 时，界面和实际加载保护同步为 3 GiB / 自动恢复 3.5 GiB；未启用的新旧运行时仍使用原保护线。原生库能力校验失败会明确报错，不假装已经省内存。升级原生 DLL 和 Python 后再启用此配置，改为 false 可回退整表加载。低功耗开关及休眠条件不变。
