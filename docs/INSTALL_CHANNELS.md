# 安装渠道与版本一致性

作者 Asryto。普通用户只下载 Releases 最新正式版的一份完整 ZIP，双击 install.cmd。包内已有 World、Qwen3-TTS 小模型与运行环境。

市场版与本地版共用 npm 包名 `cortico-world-soft-voice`、World ID `soft-voice` 与 Bot 数据目录。构建器先执行真实 `npm pack`，再从同一 TGZ 解出 World 装入完整包与代码更新包，并逐文件验证字节一致。发行后才可称为市场已发布；本地构建或 GitHub Release 不代表 npm 发布成功。

安装器读取实际 `node_modules` 包版本，解析官方 pnpm 的目录链接，不依赖用户记忆的安装渠道：

| 检测结果 | 处理 |
| --- | --- |
| 未安装 | 安装扩展并接入模型 |
| 比完整包旧 | 备份并更新扩展 |
| 同版本且文件一致 | 跳过扩展覆盖，继续模型接入 |
| 同版本但包文件损坏 | 修复包文件 |
| 已安装更新版本 | 保留新版，继续模型接入，不降级 |

依赖登记保持为市场可识别的准确版本，不使用 `file:` 本地依赖阻断市场更新。市场版可以被新版完整包或用户主动代码更新覆盖；本地版也可以由市场升级。替换文件先写临时文件再原子替换，不修改 pnpm 共享硬链接的原始存储。

个人设置、语音开关、音色、模型和其它扩展不作为 World 包文件覆盖。需要重启时先提示确认；未确认就延期。程序内只自动检查并提示，用户主动更新后才下载、验证、备份、安装、校验，失败回滚。

验证脚本：`python scripts/verify_install_channels.py --output 结果.json`。使用隔离的本地 npm 注册表与真实 pnpm，验证市场→本地、旧本地包保留新市场版、本地→市场、市场→GitHub 更新，核对每个 World 文件与个人数据保留。此测试不向公网发布，也不代表 GPU 性能测试。
