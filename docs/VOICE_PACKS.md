# 本地语音助手：音色制作与 ZIP 导入

这份教程制作的是 **参考音色包**：用一段干净人声和逐字对应文本，让现有 Qwen3-TTS Base 模型提取音色特征。无需重新训练模型，也不是给每句话预先录音。导入音色不会更换模型或使用云端服务。

## 1. 准备参考人声

选取你自己录制、获得授权或允许这种用途的合成人声。准备一段 **3–15 秒**、单人、中文、完整语句的素材；建议先用 5–10 秒。保持自然音量与语调，不要用夸张喊叫作为整套声音的参考。

优先选择没有背景音乐、混响、游戏音效和重叠说话的原始人声。降噪、去混响、变调过重会把金属音、鼻音或发声抖动带进合成。声音过尖、沙哑或断续时，先更换更干净的参考，不要一味拉高音调。

在音频编辑器中裁剪到完整句子，去掉首尾长静音，导出 **WAV / 单声道 / 24000 Hz / PCM 16-bit**。也可使用已经安装的 FFmpeg：

```powershell
ffmpeg -i input.wav -ac 1 -ar 24000 -c:a pcm_s16le reference.wav
```

这条命令只转换格式，不保证降噪效果。保留原始文件以便重新裁剪。

## 2. 写准确转录文本

完整写出音频中实际说出的句子，包括语气词。不能填“软萌少女声”等风格提示来代替转录，也不能放另一段台词。当前版本仅接入中文音色包。

例如参考中确实说的是：

> 今天也辛苦啦，先休息一小会儿，我会乖乖等你。

那么 `referenceText` 就应是这句话。不要用这段示例配不相符的其他声音。

## 3. 一条命令打包

先按仓库部署指南安装 Python 运行环境。在仓库根目录执行：

```powershell
.runtime-native\venv\Scripts\python.exe -m coopanion_soft_voice.voice_pack create --wav reference.wav --output my-voice.zip --id my-voice --name "我的音色" --text "音频里实际说出的完整句子"
```

`id` 为 3–48 位小写英文字母、数字、连字符，且以字母开头。输出文件已存在时会拒绝覆盖，请换一个新文件名。
脚本会检查采样格式、3–15 秒长度和基本音量，自动填写 SHA256。它不能判断是否好听、转录是否准确或素材是否包含音乐；这些需要你试听确认。

ZIP 根目录应是下面两项，不要套额外文件夹：

```text
my-voice.zip
├── voice.json
└── reference.wav
```

自动生成的 `voice.json` 结构如下；SHA256 必须是实际音频的校验值：

```json
{
  "format": "local-voice-pack",
  "version": 1,
  "id": "my-voice",
  "name": "我的音色",
  "referenceText": "音频里实际说出的完整句子",
  "language": "Chinese",
  "sha256": "由打包命令自动生成"
}
```

ZIP 最多 2 MiB。只接受这两个数据文件，拒绝脚本、额外目录、重复文件、加密包、路径穿越及损坏校验。导入端不执行包内代码。

## 4. 导入并选用

1. 打开 **本地语音助手 → 音色库**。
2. 选择 ZIP，点击 **校验并导入 ZIP**。
3. 导入只增加选项，不会自动换声。点击新音色的 **使用此音色**。
4. 等待当前播放完成后切换；模型会停止、重新提取参考特征并预热，加载前仍需至少 4 GiB 空闲内存。
5. 到 **语音控制** 点击 **试听一句**，再测试几条不同长度的聊天内容。

可以随时选回 **当前已确认音色**。**新版默认音色 · 待更新** 是不可选择的预留项，并不代表已提供第二种音色。
同一包重复导入不产生重复选项；同名但不同音频或转录会生成独立版本。已有选项不会被静默覆盖。

## 5. 试听与性能检查

至少分别试听短句、带停顿的句子和较长句子，关注咬字、句尾截断、气息、鼻音与语调是否自然。不要只用一句“你好”判断整套声音。

在 **运行状态** 观察实际首次出声曲线、平均合成用时/音频时长以及断流/设备欠载。指标只代表速度和连续性，不代表音色审美；没有样本时显示空态。
新音色可能比内置参考更慢或更不稳定。若出现重复、截断、明显不自然，换短一些、转录更准确、噪声更少的参考后重新打包。

## 常见问题

| 提示或现象 | 处理 |
|---|---|
| 非 PCM16、双声道或采样率不符 | 按第一步重新导出，不能只改文件后缀 |
| SHA256 不匹配 | 用打包命令重新生成 ZIP，不手工跳过检查 |
| ZIP 根目录不符合 | 直接压缩两个文件，不压缩它们外层的文件夹 |
| 缺少参考文本 | 补完整准确转录；不要填角色介绍或风格提示 |
| 加载内存不足 | 先释放内存；自动恢复开启时等待空闲达到 4.5 GiB |
| 导入后声音没变 | 导入与启用分开，需要点“使用此音色” |
| 参考格式正确但不好听 | 格式检查无法保证效果，需要换参考并实际试听 |

分享 ZIP 只需要这两个文件，不需要带上模型权重、Python、账号配置或聊天记录。
