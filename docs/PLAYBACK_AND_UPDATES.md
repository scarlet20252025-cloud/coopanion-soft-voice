# 播放策略、设备切换与热更新

作者 Asryto。适用于引擎 0.5.0 / World 0.4.0。

## 播放不断续

RTF = 合成秒数 / 音频秒数。持续生成的速度比实时慢（RTF > 1）时，固定 1.2 秒缓冲迟早会耗尽；调高 CPU 线程或播放器检查频率不能替代 GPU 的生成速度。跨句的重新预填充和调度抖动也会影响实际连续性，因此 RTF < 1 不是不掉音的充分保证。

“语音控制 → 播放策略”有三个选项，保存后下一句话生效：

| 选项 | 行为与取舍 |
| --- | --- |
| 自动（默认） | 在首个可播放样本之前检查原生生成节奏。可靠测量低于 0.8× 时保留流式；偏慢或测量不足先合成整句。实际欠载后，本工作进程后续自动模式优先完整缓冲 |
| 优先连续 | 全部短段合成完成后才开始设备播放，避免合成速度不足造成静音空洞；需要等待完整合成 |
| 优先开口 | 保留边生成边播，慢设备可能再次断续；适合愿意用等待连续性换首声速度的用户 |

缓冲只排队保存原 PCM，不升降调、不改变采样、种子或参考音色。切换策略不会重载模型。保守选择按实际设备和音色保存，休眠唤醒后保留；主动使用流式且验收低于 0.8×、没有欠载后解除保守选择；实际音频设备/驱动欠载仍单独报告，完整缓冲不能保证修好驱动故障。

`deployment-check.json` 中 `ok=true` 表示合成与设备调用执行成功；请同时检查 `playbackHealth.smooth`、`streamingRecommended`、`effectiveMode`，以及 `underrunMs` 和 `deviceUnderflows`。它不代表主观听感已经被批准。

## 选择核显或独显

主页点“检测设备”，选择实际枚举的 Vulkan 核显/独显，再点“切换设备”。空闲时先释放旧 worker，再由新的进程加载所选设备；不迁移已经运行的 GPU 上下文，不同时驻留两套模型，不重启桌宠。

播放、排队或加载期间拒绝切换，等结束后再操作。加载失败时恢复原设备配置并尝试恢复语音，具体错误留在运行状态。不会自动回退独显、CPU 或另一块显卡。选择会保留，休眠唤醒也使用该设备。

安装器默认只自动选择唯一核显。若明确要用独显，可在安装参数添加 `-DeviceName '设备名称'`；多个同名设备或未枚举设备会拒绝，不能靠猜设备名称通过检查。Vulkan 驱动、当前至少 3 GiB 系统可用内存保护仍适用。独显与游戏共享显存；缺驱动或显存不足不代表更换音色。

不提供基于品牌名猜测的“最低 GPU 型号表”。Intel UHD 用户提供的数据是反馈证据，并非作者在 Intel 实机复测；本次作者实测设备和结果记录于 `evidence/2026-10-15-release-0.5.0/`。

NVIDIA 独显使用设备本地显存分配（`GGML_VK_DISABLE_HOST_VISIBLE_VIDMEM=1`），关闭可映射显存优先路径及系统内存回退；核显维持原分配策略。本机 RTX 4050 的 A/B/A 对照证明旧路径显著拖慢推理，具体机制不能仅凭型号推断。自动修正的通用便携包已单独实测，不能外推为所有 NVIDIA/AMD/Intel 卡的性能保证。运行状态与诊断包显示实际内存路径。

## 右上角热更新

“语音控制”右上角展开“热更新 → 检查更新”。有新版且当前是完整便携安装时，选择“下载并热更新”。源码部署不自动覆盖工作目录，请 `git pull` 后构建或使用完整包。

更新源固定为本 GitHub 仓库，下载代码 ZIP 并验证整包及每个文件的 SHA256。只更新 Python/World/安装脚本和教程；不下载/修改模型、原生 DLL、参考音色设置或用户 Bot 配置。不同原生/模型布局拒绝代码包，需要新完整包。默认启动 30 秒后检查，每 24 小时一次；检查失败一小时后重试。右上角可关闭自动检查。发现新版只提示，由用户点击“下载并热更新”后自动完成下载、校验、备份、安装与失败回滚；不会后台自动安装或自动重启桌宠。不依赖 npm 市场。

界面显示检查、真实下载/安装进度、校验和验证结果。安装前停止语音 worker，更新后恢复原来的语音开关。更新文件保存在运行目录 `updates/`，原文件备份在 `updates/backups/`；失败自动回滚，进程中断的写入有恢复记录，下次更新先回滚。

**语音引擎代码可立即生效；World 代码需要重启桌宠。** 这是 [Cortico 官方扩展规则](https://github.com/Pal-AI-Lab/Cortico/blob/main/docs/extensions.md) 的限制，面板会显示“待桌宠重启”。不修改宿主、绕过模块缓存或声称重启 World 能重新加载所有 npm 代码。

更新完成需要重启时使用官方 `ctx.ui.confirm` 提示；确认后按 Cortico 的 `requestRestart(dataDir)` 通知启动器，并调用已注册的 Coopanion 正常关闭处理，再由启动器重新加载进程。取消后保留待重启状态和按钮，不重复打断。未检测到受监管桌宠宿主时保留更新文件并提示手动重启，不强制结束进程。

下载按已收字节显示百分比，备份/安装/恢复按实际文件数显示阶段百分比；检查、校验和运行验证显示当前阶段，不能把它们编成虚假的整体进度。

0.4.11 没有更新按钮，第一次升级仍需下载 0.5.0 完整包并运行 `install.cmd`。此后匹配同一模型/原生布局的小版本可用新按钮更新。

## 发布资产约定

`releases/latest` 的正式发行页只提供完整安装 ZIP 与 SHA256，扩展和模型一次安装。npm TGZ 来自同一份构建结果，不作为第二个安装包在该入口展示。程序内代码更新 ZIP 放在 `updates-v版本` 的预发行资源页，不会成为 latest；`update-release.json` 固定该资源的 URL、大小与 SHA256。历史版本仍留在历史发行页。GitHub 自动生成的源码下载项由平台提供，不属于可安装发行包。
