# 扩展内一键部署（World 0.4.7 起）

作者 Asryto。

在语音控制页的「模型部署」卡片选择下载源，然后点击「一键部署」。World 0.4.8 起，已有模型也保留「已部署」按钮并说明无需重复下载；正常状态不显示教程，失败后才显示「手动部署指南」。安装只在用户点击后开始；后台检查更新不会下载或安装模型。

机器没有核显时（例如 Intel 型号带 F 后缀），一键部署不会替你选独显：页面会列出检测到的显卡，主按钮变为「使用所选设备继续部署」，选好后点一次即可继续，模型不会重复下载。手动运行安装包时同理，安装器会要求输入序号确认；由 AI 代跑的非交互安装必须先传 `-DeviceName "显卡名称"`。

界面显示下载百分比、速度以及校验、解压、设备配置、实际合成测试等阶段。切换页面后可以继续查看进度。取消下载保留部分文件，下次点击可续传；校验失败的文件会删除并重新获取。自动下载源依次尝试发布清单中的镜像，任何源均必须匹配同一 SHA256。

只有一台可识别核显时自动选择核显，否则先列出设备让用户选择。独显必须主动选择。内存不足时显示「安装完成，尚未通过合成验收」，不会绕过启动保护线或虚报就绪。安装测试静音，不会突然播放测试音频。

离线用户可展开「离线安装」，填写此页指定版本完整 ZIP 的绝对路径；仍会验证文件大小和 SHA256。默认至少预留约 3 GiB 磁盘空间。

此入口安装固定的引擎 0.5.3 资源，不替换已安装的 World，不降级市场扩展，不覆盖已有可用模型配置。已有有效运行时会直接保留。模型资源版本和 World 界面版本分别显示；以后代码升级仍走独立的手动更新流程，需要重启时先提示确认。

国内资源仓库：https://modelscope.cn/models/Asryto/QingHe-Qwen3-TTS

开发验收：下载失败切换源、Range 续传、服务器忽略 Range、取消保留部分文件、SHA256 拦截、缓存复用均有测试；真实完整包在独立目录完成解压、配置、RTX 4050 合成和静音播放。2026-10-15 已用扩展下载器匿名完整下载魔搭镜像，1169565768 字节及 SHA256 均与 GitHub 包一致；Range 请求返回 206。此本机网络结果不保证所有运营商同速。
