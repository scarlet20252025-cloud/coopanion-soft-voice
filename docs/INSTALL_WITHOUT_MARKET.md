# 轻量化本地语音引擎：不依赖扩展市场的安装教程

作者：**Asryto**。本教程使用 GitHub 完整安装包，适用于 Python 0.4.11 / World 0.3.11。

**下载完整 ZIP → 解压 → 双击 `install.cmd` → 在桌宠中试听。** 安装器会同时安装语音扩展、模型和运行环境，不需要扩展市场、npm 账号，也不用单独安装 Python、Git、Node、PyTorch、CUDA 或编译工具。

## 1. 安装前准备

- Windows 10/11 **x64**。
- 已安装并启动过一次 [Coopanion 官方桌宠](https://github.com/Pal-AI-Lab/Coopanion/releases/latest)，让它完成首次初始化。
- 一块支持 Vulkan 的核显和相应厂商驱动。只有一块核显时自动选用，多块时需要指定。AMD 核显已实测，Intel 核显尚未实机验证。
- 加载前至少 **3 GiB 系统可用内存**，约 **4 GB 可用磁盘**。这里的可用内存指任务管理器显示的“可用”，不是电脑安装的总内存；不要用独显显存大小代替。

语音合成本身不需要 API key；桌宠的文字对话仍使用你自己的聊天模型配置。没有配置聊天模型也可以单独验证语音运行包，不能据此认为桌宠已能对话。

安装前建议从桌宠菜单正常退出 Coopanion。不要只关设置窗口后认为整个桌宠已经退出。安装器能对已验证的桌宠版本尝试正常退出；不支持或退出失败时，会要求你手动退出后重试。

## 2. 下载完整安装包

直接下载：

**[coopanion-local-voice-0.4.11-windows-x64.zip（约 1.17 GB）](https://github.com/scarlet20252025-cloud/coopanion-soft-voice/releases/download/v0.4.11/coopanion-local-voice-0.4.11-windows-x64.zip)**

也可以打开 [GitHub 发布页](https://github.com/scarlet20252025-cloud/coopanion-soft-voice/releases/tag/v0.4.11)，在 Assets 中选择同名文件。

该完整包包含 Qwen3-TTS 0.6B Base Q8 精简模型、音频解码模型、Vulkan 推理引擎、Python 3.12、播放器依赖、已确认音色和独立 World 扩展。

发布页中的 `cortico-world-soft-voice-0.3.11.tgz` 只包含扩展界面与代码；`Source code (zip)` 是源码。**首次安装请选上面约 1.17 GB 的完整 ZIP**，单独下载 TGZ 或源码无法完成模型部署。

## 3. 解压并安装

1. 将 ZIP **完整解压**到英文目录，例如 `D:\CoopanionVoice`。不要直接在压缩包内部运行安装器。
2. 打开解压后的文件夹，找到 `install.cmd`。同一层应当能看到 `models`、`native`、`python`、`scripts`、`world` 文件夹，以及 `portable-manifest.json`。
3. 双击 **`install.cmd`**。
4. 安装器自动查找正在运行的 Coopanion、桌面和开始菜单快捷方式、安装记录与常见目录。找到一个有效副本时自动使用；找不到或有多个副本时会显示文件夹选择框。
5. 需要选择时，选择 **直接包含 `Coopanion.exe` 的文件夹**。不要选择它下面的 `data`、`resources` 或语音安装包文件夹。可以通过桌宠快捷方式的“打开文件所在的位置”查找。

安装器依次显示：

| 步骤 | 含义 |
| --- | --- |
| `[1/3] Checking bundled model...` | 校验运行文件，并选择核显；随后显示 `GPU: 设备名称` |
| `[2/3] Testing real synthesis...` | 实际生成语音，验证静音播放和音频输出 |
| `[3/3] Installing the independent World...` | 安装扩展，登记本机语音路径，备份相关配置 |

**第 2 步是静音测试，安装过程中听不到声音是正常的。** 等到出现 `Installed. Open Lightweight Local Voice Engine...`，安装才算成功；失败时窗口会保留错误信息，不要把关闭窗口当成安装完成。

成功后安装器会打开桌宠。若没有自动打开，请从原来的 Coopanion 快捷方式启动。无需再从扩展市场安装，也无需手动修改配置文件。

## 4. 开启语音并确认成功

1. 在桌宠设置左侧的 World 列表打开 **轻量化本地语音引擎**。
2. 进入 **语音控制**。如果主按钮显示“开启语音”，点击它并等待加载；如果已显示“停止语音”，说明语音开关已经开启。
3. 查看右侧“模型部署检测”和左侧“播放状态”。出现 **“已连接 · 可以发声” / “就绪”** 后，点击 **“试听一句”**。
4. 确认听到声音，并检查音量和 Windows 的输出设备。首次加载可能需要等待，安装器和面板不会给出虚假的完成百分比。

| 状态 | 下一步 |
| --- | --- |
| 未部署 / 文件缺失 | 重新运行完整包的 `install.cmd`；确认包已完整解压且目录没有被删除 |
| 已部署 · 尚未连接 | 点击“开启语音”，等待模型准备完成 |
| 已部署 · 正在连接 | 等待，查看加载阶段；想中断可点击同一主按钮取消 |
| 已连接 · 可以发声 | 点击“试听一句”；之后桌宠的 `pet_say` 文本会自动朗读 |
| 已部署 · 低功耗休眠 | 已经安装成功；下一句话或试听会自动唤醒，可能增加等待 |
| 等待内存 | 释放暂时不用的程序内存后重试；自动恢复门槛为 3.5 GiB |
| 模型连接失败 | 到“运行状态”查看具体错误，并查看下方日志位置 |

“气泡同步”是独立选项，首次默认开启：等本段语音实际读完，再切换下一段气泡。可以单独关闭。低功耗模式也是可选开关，开启后空闲时释放模型、下次说话自动唤醒；它不减少合成时的模型需求。

## 5. 常见问题

| 问题或提示 | 处理方法 |
| --- | --- |
| `Initialize Coopanion once...` / 缺少 `config.json` | 先启动桌宠完成初始化，再正常退出并重试；也检查是否选错桌宠文件夹 |
| `Extract the ZIP to an English path...` | 将整个语音包重新解压到英文路径，例如 `D:\CoopanionVoice` |
| 桌宠未找到或有多个副本 | 在选择框中选你实际使用的 `Coopanion.exe` 所在文件夹 |
| `Exit Coopanion...` / `Coopanion is still running` | 从桌宠菜单正常退出整个应用，再运行安装器 |
| `Native voice needs at least 3 GiB free RAM...` | 释放可用内存后重试；不要为了通过检查而下调保护线 |
| 没有可用核显、Vulkan 或驱动错误 | 检查核显是否可用、厂商驱动是否安装；不自动回退独显。多核显时按下一节指定 |
| 安装时没听到声音 | 安装测试故意静音。成功进入面板后，用“试听一句”确认 |
| 试听有声音，但桌宠不回复 | 再检查桌宠的聊天模型连接与对话；语音模型不负责生成聊天回复 |
| 更新桌宠后气泡不再等待语音 | 完整包的气泡桥验证于官方桌宠包 0.1.4；未知版本或结构变化会提示。不要反复覆盖未知版本，可先关闭气泡同步 |

日志和验收文件位于**你解压的语音文件夹**中：

- `installation.log`：安装错误和推理库诊断。
- `verification/deployment-check.json`：真实合成与播放验证结果，成功时 `ok` 为 `true`。
- `verification/deployment-preview.wav`：安装测试生成的音频，可用播放器打开。

反馈问题时提供最后的错误信息，以及系统、核显型号和扩展版本即可；不要提供聊天模型密钥或整个个人配置文件。

## 6. 自动识别失败时指定目录

普通安装不需要命令行。仅在自动识别或特殊目录布局需要明确参数时，打开 PowerShell，执行下列命令，**将示例目录替换为你自己的路径**：

```powershell
Set-Location 'D:\CoopanionVoice'
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-portable.ps1 -CoopanionRoot 'D:\Apps\Coopanion'
```

如果电脑有多块核显，安装日志会列出可选名称。在命令末尾添加 `-DeviceName '安装器列出的核显名称'`。默认 Bot 目录名为 `companion`；使用其他 Bot 时添加 `-BotId '你的Bot目录名'`。

其他可选参数：`-NoLaunch` 安装后不打开桌宠；`-RuntimeOnly` 只验证语音运行包、不接入桌宠；`-NoEnableSpeech` 不主动开启语音，保留既有开关选择（新安装保持关闭）。

## 7. 更新、迁移与保留文件

**保留解压目录。** 桌宠会从里面运行 Python 和模型，不能在安装成功后把它当成临时安装文件夹删除。

使用本地完整包时，语音扩展不会通过 npm 查询更新。以后在 GitHub 下载新的完整包，解压到英文目录，正常退出桌宠后运行新版 `install.cmd`，指定同一个桌宠即可。安装器备份相关配置，保留既有音量、气泡同步和低功耗选择；默认会开启语音，需要保留关闭状态时使用 `-NoEnableSpeech`。

搬到其他英文目录后重新运行安装器，让它重新登记本机路径。搬到另一台电脑时，也需要重新运行，以重新选择那台电脑的核显；不要复制作者或原电脑的路径配置来代替安装。

相关配置备份保存在 `Coopanion目录/data/home/Bot目录/data/soft-voice/backups/时间戳`。这是安装器备份的配置和扩展文件，不是整个桌宠数据的完整备份。

下载后的完整包可离线执行语音安装和推理；桌宠聊天模型是否需要联网取决于你自己的聊天模型配置。作者、模型和第三方依赖许可证见包内 `LICENSE`、`THIRD_PARTY_NOTICES.md` 与 `licenses`。
